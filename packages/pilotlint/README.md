# pilotlint

Fast, structure-agnostic architecture checks for TypeScript projects, built for AI agents.
See the [repository README](../../README.md) for configuration, commands, and agent
integration. The agent skill is in [`skills/pilotlint/SKILL.md`](./skills/pilotlint/SKILL.md).

```bash
pilotlint check --changed --new
pilotlint describe src/features/calendar
pilotlint rules explain boundaries/entry-only
```
