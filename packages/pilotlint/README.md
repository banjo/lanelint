# pilotlint

pilotlint keeps coding agents on course. It is a fast architecture linter for TypeScript
projects, built for code written by AI agents.

```bash
pilotlint check --changed --new
pilotlint describe src/features/calendar
pilotlint rules explain boundaries/entry-only
```

This package has the CLI, `defineConfig`, and the agent skill in
[`skills/pilotlint/SKILL.md`](./skills/pilotlint/SKILL.md). Start with
[Getting started](../../docs/getting-started.md), and see the [docs](../../README.md#docs)
for the rest.
