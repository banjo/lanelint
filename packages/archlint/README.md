# archlint

Fast, structure-agnostic architecture checks for TypeScript projects, built for AI agents.
See the [repository README](../../README.md) for configuration, commands, and agent
integration. The agent skill is in [`skills/archlint/SKILL.md`](./skills/archlint/SKILL.md).

```bash
archlint check --changed --new
archlint describe src/features/calendar
archlint rules explain boundaries/entry-only
```
